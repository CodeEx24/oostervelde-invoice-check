# Woonkring Oostervelde invoice check: dataset

Everything you need for the MSTR assignment. Read the assignment brief first.

| Path                           | What it is                                                           |
| ------------------------------ | -------------------------------------------------------------------- |
| `task-audit-transcript.md`     | The task audit with Sanne, accounts payable at Woonkring Oostervelde |
| `contract-excerpt.md`          | Article 4 of the framework contract (Dutch)                          |
| `price-agreement-2025.csv`     | The price list, 2025 prices excluding VAT                            |
| `work-orders-export.csv`       | All January work orders: type, maximum hours, approvals, build year  |
| `invoices/`                    | 40 contractor invoices from January 2026, as text (Dutch)            |
| `reference/sanne-verdicts.csv` | Sanne's own verdicts on the first 10 invoices                        |

Woonkring Oostervelde, the contractors, the people, and their registration and bank numbers are made up.

The invoices and the contract are in Dutch, like our clients' data. You don't need to speak Dutch, but you do need to understand it. Translate what you need, and work out for yourself what each rule and each invoice line means.
